# موقع شركة كور ليفت للمصاعد

موقع تعريفي عربي (RTL) لشركة كور ليفت — حلول المصاعد المتكاملة، الرياض، المملكة العربية السعودية.
بُني كموقع ثابت (HTML/CSS/JS) بدون أي مكتبات خارجية، على نمط مواقع شركات المصاعد العالمية مثل Otis.

## التشغيل محلياً

```bash
node server.mjs
```

ثم افتح `http://localhost:4173` في المتصفح.

> يمكن أيضاً فتح `index.html` مباشرة بالنقر المزدوج، لكن تشغيل الخادم أدق لأن الخطوط والصور تُحمَّل بمسارات نسبية.

## الصفحات

| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية — الواجهة، الإحصائيات، أنواع المصاعد، التشطيبات، الخدمات، الشركاء |
| `products.html` | المنتجات والحلول — 6 أنواع مصاعد بجداول مواصفات + التشطيبات |
| `services.html` | الخدمات والصيانة — 4 خدمات، آلية العمل، الأسئلة الشائعة |
| `partners.html` | شركاؤنا — المكائن المعتمدة (5 مصنّعين) + شركاء النجاح (27 جهة) |
| `about.html` | من نحن — القصة، القيم، الوظائف |
| `contact.html` | تواصل معنا — بيانات التواصل + نموذج طلب عرض سعر |

## البنية

```
assets/
  css/style.css     نظام التصميم كاملاً (متغيرات CSS، مكونات، استجابة للشاشات)
  js/main.js        القائمة المتنقلة، القوائم المنسدلة، الأكورديون، العدّادات، النموذج
  fonts/            خط ثمانية (Thmanyah Sans + Serif Display) بصيغة woff2
  img/              صور المصاعد والشعار مستخرجة من ملف البروفايل
  img/brands/       شعارات المصنّعين: SICOR · Alberto Sassi · Montanari · Fuji · Vert
  img/partners/     شعارات شركاء النجاح
server.mjs          خادم معاينة محلي بسيط
```

## الهوية البصرية

اتجاه **معماري/تحريري** بدل النمط الشركاتي المعتاد:

- **اللون**: خلفية ورقية دافئة `#F4F2ED` وحبر شبه أسود `#15171A`. الأزرق `#1E88CF`
  لون العلامة ويُستخدم كلمسة فقط — تحته خط، أيقونة، مؤشّر — لا كخلفيات ملوّنة.
- **الخط**: العناوين بـ `Thmanyah Display` (الوجه الشعري)، والنصوص بـ `Thmanyah Sans` وزن خفيف.
- **البنية**: خطوط شعرية رفيعة بدل الكروت والظلال، صفر انحناء في الزوايا،
  وشبكة منتجات غير متناظرة (العمود الأوسط منزاح للأسفل).
- **الصور**: رمادية جزئياً وتستعيد لونها عند المرور عليها.
- **لمسة المصعد**: مسطرة رأسية رفيعة على حافة الصفحة يتحرّك عليها مؤشّر أزرق
  بحسب موضع القراءة، ولوحة طابق في الواجهة.

## الخط

الموقع يستخدم **خط ثمانية** بوجهيه: `Thmanyah Sans` (Light/Regular/Medium/Bold/Black)
و`Thmanyah Display` (Medium/Bold)، محمّلاً محلياً من `assets/fonts/`.
ملف الترخيص مرفق في `assets/fonts/LICENSE.pdf` — راجعه قبل النشر التجاري.

## ملاحظات قبل النشر

1. **نموذج التواصل** في `contact.html` تجريبي حالياً (يعرض رسالة نجاح دون إرسال فعلي).
   لتفعيله اربطه بخدمة نماذج مثل Formspree أو بنقطة نهاية على الاستضافة، وعدّل معالج
   `form[data-mock]` في `assets/js/main.js`.
2. **حسابات التواصل** مربوطة بالحسابات الفعلية:
   [إنستغرام](https://www.instagram.com/coreleft.sa/) و[تيك توك](https://www.tiktok.com/@coreleft.sa)
   (المعرّف `@coreleft.sa`) إضافة إلى واتساب. لا توجد حسابات لينكدإن أو إكس فحُذفت أيقوناتهما.
3. **رابط الخريطة** في صفحة التواصل صندوق ثابت — يمكن استبداله بـ iframe من خرائط جوجل
   بإحداثيات المقر.
4. **المواصفات الفنية** في جداول `products.html` (الحمولات والسرعات) قيم قياسية للصناعة
   وليست منقولة من ملف البروفايل — راجعها مع الفريق الفني قبل النشر.
5. الشعارات والصور مستخرجة من ملف `CoreLift Profile.pdf` المقدّم من الشركة.
